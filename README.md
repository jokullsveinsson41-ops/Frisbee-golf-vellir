# Frisbee-golf-vellir

## Disc Golf Iceland platform

The full-stack Disc Golf Iceland upgrade is in [`platform/`](platform/README.md). It includes a source-checked course directory, interactive atlas, course profiles, bilingual navigation, saved courses, trip planning, scorecards, community moderation, and server-side AI, weather, and routing integrations.

[Open the private review site](https://disc-golf-iceland.jokullsveinsson41.chatgpt.site) (owner access).

The original static pages remain at the repository root. See [platform/README.md](platform/README.md) for setup, data coverage, integration requirements, and verification results. AI and road estimates need server credentials; administrator access needs an explicit allowlist. National coverage and browser QA are not yet complete.
